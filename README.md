# Набор аддонов для WoW-Forever

Готовая сборка необходимых и полезных модификаций интерфейса для комфортной игры на сервере WoW-Forever.

## Как установить

1. Скачайте этот архив из репозитория и распакуйте.
2. Перенесите содержимое в папку с вашей игрой по пути: `World of Warcraft\_forever_\Interface\AddOns\`.
3. Убедитесь, что в меню выбора персонажа в разделе «Модификации» включена галочка **«Устаревшие модификации»**.
4. Добавьте вашу папку с игрой в приложении curseforge и обновите все аддоны.

## Описание аддонов в сборке

### 🎨 Кастомизация интерфейса и шрифты

- **EllesmereUI** — Модификация игрового интерфейса (юнит-фреймы, панели команд, мини-карта) в фирменном минималистичном стиле.
  - 📄 `EllesmereUI_profile.txt` — готовый авторский профиль настроек для этого аддона.
- **Lueur** — Аддон для добавления красивого свечения и визуальной подсветки (glow-эффектов) для кнопок заклинаний, проков способностей, сумок и элементов интерфейса, квестовых заданий и предметов, ресурсов в мире.
- **FontMagic / FontMagicCustomFonts** — Модификация для легкой глобальной замены стандартных игровых шрифтов на кастомные.
- **BlizzThreatPlates-Forever** — Кастомизированные индикаторы здоровья (неймплейты) над головами противников с удобным отображением уровня угрозы (агро), слева от неймплейта. (Нужно проверить работоспособность с неймплейтами EllesmereUI)

### ⚔️ Рейды, подземелья и боссы (Boss Mods)

- **BigWigs (и его модули)** — Главный рейдовый босс-мод. Отслеживает таймеры способностей боссов, фазы боя, дает звуковые и визуальные подсказки.
  - Включает базовые файлы (`BigWigs`, `BigWigs_Core`, `BigWigs_Options`, `BigWigs_Plugins`) и модули под разные версии: `BigWigs_MarchOfQuelDanas`, `BigWigs_MidnightLairs`, `BigWigs_MidnightWorld`, `BigWigs_Sporefall`, `BigWigs_TheOceanrift`, `BigWigs_TheUnbindingOfAlthix`, `BigWigs_VenomousAbyss`, `BigWigs_TheVoidspire`.

### 🗺️ Квесты, прокачка и навигация

- **Questie** — Полноценный помощник по заданиям. Отображает доступные квесты, места выполнения и цели прямо на карте и миникарте.
- **RXPGuides** (RestedXP) — Интерактивный внутриигровой гид по самой быстрой и оптимизированной прокачке персонажа.
  - ℹ️ **Инструкция:** Пошаговый гайд по генерации строк импорта и активации кастомных роутов прокачки доступен на сайте [Forever RXP](https://rxp.kostya.sexy/).
- **MerchantMap** — Отображает торговцев и их ассортимент прямо на глобальной карте мира.
- **LayerSwap** — Утилита для удобного и быстрого переключения между слоями (зеркалами) в перенаселенных игровых зонах.
- **HandyNotes** — Базовый аддон для создания, редактирования и отображения кастомных меток/значков прямо на карте мира и миникарте.
- **HandyNotes: WoW Forever** — Специализированный плагин (база данных для HandyNotes), отображающий полезные серверные точки, скрытые сундуки, квестовые объекты и раритеты сервера WoW-Forever.
- **TomTom** — Навигационный компас. Добавляет на экран 3D-стрелочку направления к точкам по заданным координатам, отлично работает в связке с другими аддонами.

### 📊 Базы данных и полезные утилиты

- **ForeverDungeonJournal** — Кастомный атлас подземелий, доработанный специально под особенности и списки лута WoW-Forever.
- **AlexAtlasLoot** — Внутриигровая база данных добычи (лута) с боссов, наград за репутацию, фракций и профессий.
- **ItemTree** — База данных предметов и рецептов профессий со структурным деревом крафта.
- **Plumber** — Полезный набор микро-утилит для оптимизации интерфейса, удобных всплывающих подсказок и автоматизации рутинных действий.
- **TrainerSpells** — Показывает прямо в спеллбуке, какие заклинания станут доступны вам на будущих уровнях.
- **ForeverIRS** — Специализированный модуль для отображения уникальных игровых механик или валют сервера.

### 🛠️ Системные (Исправление ошибок LUA)

- **!BugGrabber** — Сборщик системных ошибок Lua. Работает в паре с BugSack, не позволяя всплывающим окнам ошибок мешать игровому процессу.
- **BugSack** — Удобный графический интерфейс (иконка у карты) для просмотра и фильтрации пойманных ошибок Lua.
